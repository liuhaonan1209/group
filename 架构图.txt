                                 技术架构特点
═══════════════════════════════════════════════════════════════════════════════════

1. 微服务架构
   • 服务拆分: 按业务域拆分为路线管理、财务管理等独立服务
   • 服务通信: 基于Kitex的高性能RPC通信
   • 服务治理: 支持服务发现、负载均衡、熔断降级

2. 分层架构设计
   • 展示层: Vue 3 + Element Plus 现代化前端
   • 网关层: Hertz HTTP框架提供RESTful API
   • 服务层: Kitex RPC框架提供高性能服务调用
   • 业务层: 核心业务逻辑处理
   • 数据层: MySQL持久化 + Redis缓存

3. 核心业务特性
   • 智能站点排序: 基于行驶时间的自动排序算法
   • 数据一致性: 站点去重和冲突检测机制
   • 实时财务: 实时数据同步和异常检测
   • 灵活结算: 多维度结算报表和自动账单生成

4. 技术栈优势
   • 高性能: Go语言 + Kitex RPC + Hertz HTTP
   • 现代化: Vue 3 + TypeScript + Element Plus
   • 可扩展: 微服务架构支持水平扩展
   • 可维护: 清晰的分层设计和模块化开发

5. 部署架构
   • 容器化: Docker容器化部署
   • 编排: Kubernetes集群管理
   • 监控: 完整的监控告警体系
   • 高可用: 多实例部署和故障转移
